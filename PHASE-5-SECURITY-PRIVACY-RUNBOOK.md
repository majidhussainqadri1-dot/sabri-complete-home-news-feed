# Phase 5 Security and Privacy Runbook

Fail closed on missing permission, unknown state, invalid identifier, disabled gate, unavailable dependency, cache uncertainty, or malformed object relationship. Block private-state enumeration, CSRF, IDOR, XSS, SQL injection, SSRF, unsafe redirects, MIME spoofing, polyglots, preview replay, rate-limit bypass, and private-data caching. Privacy scanner returns category names only. Public outputs exclude private notes, user/contact identifiers, patient data, tokens, hashes, capabilities, IPs, user agents, and unpublished decisions.
