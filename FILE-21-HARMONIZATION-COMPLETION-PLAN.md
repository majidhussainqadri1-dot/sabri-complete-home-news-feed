## Safety boundaries

- Work only on dedicated branches and Draft pull requests.
- No direct write to either repository's `main` branch.
- No live WordPress or Hostinger deployment.
- No blind bulk publication or migration.
- No legacy-content deletion.
- No private-count, private-metadata or patient-identity disclosure.
- Any runtime correction restarts exact-head continuous QA from zero.

## Definition of completion

Coding is not complete until all mandatory workstreams have executable code, negative tests, package tests, File 20 integration tests, exact-head artifacts, and a zero Critical/High defect record. Live visual acceptance remains a separate external gate.
