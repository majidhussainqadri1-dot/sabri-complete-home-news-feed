# Phase 5 Editorial Operator Runbook

Operational order: create/verify sources; assign revision-specific reviews; receive and assess submissions; convert accepted submissions to independent drafts; schedule without automatic publication; activate Breaking News only for public eligible articles; process corrections/retractions through the ledger; monitor diagnostics, cron, audit integrity, cache invalidation, feeds, sitemap, translations, and release blockers.

Every state-changing action requires authentication, exact capability, object-level policy, nonce for browser/REST writes, validation, and an audit event.
