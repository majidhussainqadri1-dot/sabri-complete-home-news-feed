# Phase 5 Role and Capability Matrix

- Administrator, Founder, Editor-in-Chief: all Phase 5 capabilities.
- Managing Editor: all except release promotion.
- Editor: source/review/submission/breaking/correction/translation operations, excluding release and privacy administration.
- Medical Reviewer: medical review and bounded audit access.
- Translator: translation review operations only.
- Verified Doctor: submission only.

Actor identity always comes from the authenticated WordPress session. Submitted actor/owner/reviewer identifiers never replace current identity. Assignment requires a separate capability and target-user validation.
